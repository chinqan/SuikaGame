# Phase 4：視覺風格與環境敘事（art-style-director）

> **調用 Skill**：`art-style-director`
> **產出檔案**：`docs/gdd/04_art_style_and_narrative.md`
> **前置依賴**：Phase 2 形狀表、Phase 3 渲染設定

---

## Step 4.1 — 風格定義

1. 定義 **3-5 個風格關鍵詞** + 參考作品
2. 定義不可違反的視覺原則

```markdown
**風格關鍵詞**：[A] × [B] × [C]

| 原則 | 規則 |
|------|------|
| ... | ... |

### 風格參考
- **[作品 A]**：[參考什麼元素]
```

**檢查點**：
- [ ] 關鍵詞互不矛盾
- [ ] 有具體參考作品而非抽象形容

## Step 4.2 — 配色系統

### 環境配色表

| Token | HEX | 用途 | 敘事意義 |
|-------|-----|------|---------|
| bg-primary | ... | 全域背景 | [為什麼這個色？] |
| accent | ... | 強調色 | ... |

### 形狀配色弧線

| 等級 | 顏色 | 色系 | 敘事意義 |
|------|------|------|---------|
| Lv.0 | ... | 冷色 | [起點] |
| Lv.最大 | ... | ... | [終點] |

**檢查點**：
- [ ] 每個顏色有敘事意義
- [ ] 鄰近等級無相近色
- [ ] 深色背景上高對比可辨

## Step 4.3 — 形狀繪製架構

定義形狀的多層視覺結構：

```
Layer N (外): [效果] — [用途]
Layer 2 (中): [效果] — [用途]
Layer 1 (內): [效果] — [用途]
```

### 每層詳細規格

| 層 | 繪製參數 | alpha 公式 | 繪製順序 |
|----|---------|-----------|---------|
| Glow | [半徑擴張公式] | [公式] | [先/後] |
| Main | [填充+邊框] | ... | ... |

> **品質要求**：記錄繪製迴圈方向（由外到內 or 由內到外）

**檢查點**：
- [ ] 每層有完整參數
- [ ] alpha 有公式而非只有近似值
- [ ] 多邊形 vs 圓形的差異有定義

---

## Step 4.4 — 環境場景元素

逐一定義每個場景元素，使用以下模板：

```markdown
### [元素名稱]

| 屬性 | 值 | 說明 |
|------|-----|------|
| ... | ... | ... |

> **氛圍意圖**：[這個元素對玩家產生什麼感受]
```

必須涵蓋的元素：
- [ ] 透視地板（結構參數 + alpha 梯度）
- [ ] 牆壁發光效果
- [ ] Game Over 判定線
- [ ] 動態光流效果（如有）
- [ ] 背景微元素（極淡但不可或缺的元素）

**檢查點**：
- [ ] 每個元素有「氛圍意圖」
- [ ] 動態元素有 Texture 規格（每層尺寸/顏色/alpha/繪製順序）
- [ ] 狀態轉變時的氛圍變化有描述
