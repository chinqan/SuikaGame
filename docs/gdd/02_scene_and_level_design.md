## 2.1 遊戲場景結構

本遊戲為**單一場景**（Single Scene）設計，所有互動在同一畫面上完成，由圖層（Layer）系統管理渲染深度。

### 設計解析度

| 參數 | 數值 |
|------|------|
| 畫布寬度（DESIGN_W） | 546px |
| 畫布高度（DESIGN_H） | 779px |
| 遊戲區域高度 | 709px（DESIGN_H - FLOOR_AREA_H） |
| 地板區域高度（FLOOR_AREA_H） | 70px |

### 遊戲區域分割圖

```
┌─────────────────────────────────────┐  Y=0
│           HUD（分數 + NEXT 預覽）       │  (HTML DOM 層)
├─────────────────────────────────────┤
│ GAME OVER LINE (Y=55, 紅色虛線)        │  判定線
│                                     │
│    ← 遊戲區域 →                        │
│    X_LEFT=35    X_RIGHT=511          │
│                                     │
│    （物理容器，形狀落下堆疊區）          │
│    寬度: 476px                        │
│                                     │
│─────────────────────────────────────│  Y=709
│       3D 透視地板（Floor Area 70px）    │
└─────────────────────────────────────┘  Y=779
│       Evolution Bar（演化條）          │  (HTML DOM 層)
```

### 牆壁設定

| 牆壁 | 位置 | 物理厚度 |
|------|------|---------|
| 左牆 | X=35 | 30px |
| 右牆 | X=511 | 30px |

## 2.2 圖層（Layer）系統

渲染由 7 層 PixiJS Container/Graphics 組成，從底到頂：

| # | 圖層名稱 | 類型 | 用途 |
|---|---------|------|------|
| 1 | `bg` | Container | 背景格線、3D 透視地板、格線光流粒子 |
| 2 | `wallGlow` | Container | 左右牆壁與底部的霓虹發光線條 |
| 3 | `gameOverLine` | Graphics | 紅色虛線 Game Over 判定線 |
| 4 | `shapes` | Container | 所有遊戲中的幾何形狀 Sprite |
| 5 | `particles` | Container | 合成爆炸粒子（Ring/Shard/Dot） |
| 6 | `ui` | Container | 浮動分數文字、COMBO 提示文字 |
| 7 | `aimGuide` | Container | 投放瞄準線 + 預覽幽靈形狀 |

## 2.3 難度系統（關卡設計）

本遊戲以**難度（Difficulty）**替代傳統關卡，共 3 種，每局開始前選擇：

| 難度 | 形狀起始 Index | 形狀總數 | 可投放最大等級 | 投放形狀池範圍 |
|------|--------------|---------|-------------|-------------|
| **EASY** | `slice(2)` | 7 種 | Lv.3（Pentagon） | Lv.0 ~ Lv.3 |
| **NORMAL** | `slice(1)` | 8 種 | Lv.3 | Lv.0 ~ Lv.3 |
| **HARD** | `slice(0)` | 9 種（全部） | Lv.4（Hexagon） | Lv.0 ~ Lv.4 |

### 難度設計意圖

- **EASY**：去除最小 2 種形狀（Triangle、Small Circle），有效減少小型碎片堆積，初學者友好
- **NORMAL**：去除 Triangle，平衡複雜度與可玩性
- **HARD**：所有 9 種形狀皆啟用，且可投放等級提高到 Lv.4（Hexagon），最大隨機性與空間管理挑戰

### 形狀隨機機制

- 投放形狀等級：`Math.floor(Math.random() * (maxDropLevel + 1))`
- **均勻分布**：無加權，每個等級出現機率相同
- 玩家始終可見下一個投放形狀（NEXT 預覽）

## 2.4 形狀進化（Evolution）系統

共 9 種形狀，形成線性進化鏈：

```
Lv.0 → Lv.1 → Lv.2 → Lv.3 → Lv.4 → Lv.5 → Lv.6 → Lv.7 → Lv.8
 △      ○      □      ⬠      ⬡      ●      ■      ⬣      ⬤
```

### 完整形狀定義表

| 等級 | 名稱 | 邊數 | 半徑(px) | 顏色 HEX | 顏色描述 | 得分 |
|------|------|------|---------|----------|---------|------|
| Lv.0 | Triangle（三角形） | 3 | 23 | `#00FFFF` | 青色 | 1 |
| Lv.1 | Small Circle（小圓） | 0（圓） | 29 | `#FFFF00` | 黃色 | 3 |
| Lv.2 | Square（正方形） | 4 | 36 | `#FF6B6B` | 珊瑚紅 | 6 |
| Lv.3 | Pentagon（五邊形） | 5 | 47 | `#39FF14` | 螢光綠 | 10 |
| Lv.4 | Hexagon（六邊形） | 6 | 57 | `#FF8C00` | 橙色 | 15 |
| Lv.5 | Circle（圓形） | 0（圓） | 70 | `#FF00FF` | 洋紅 | 21 |
| Lv.6 | Large Square（大正方形） | 4 | 88 | `#BF00FF` | 紫色 | 28 |
| Lv.7 | Large Hexagon（大六邊形） | 6 | 104 | `#00FF88` | 青綠 | 36 |
| Lv.8 | Large Circle（大圓形） | 0（圓） | 125 | `#FFFFFF` | 白色 | 50 |

### 合成規則

| 規則 | 說明 |
|------|------|
| 基本合成 | 兩個相同等級形狀碰撞 → 消除 + 生成下一等級形狀 |
| 得分計算 | 得分 = **目標等級**（新生成形狀）的 `score` 值 |
| 最高等級碰撞 | 兩個 Lv.8（Large Circle）碰撞 → 得 80 分，**不生成新形狀** |
| 合成位置 | 新形狀生成在兩個舊形狀的中點 |
| 合成動態 | 新形狀以隨機小速度向上噴出（vx=±0.75, vy=-1.5），增加動態感 |
| 畫面震動 | 震動量 = `4 + level × 1.5 + comboCount × 0.5`（等級越高 + COMBO 疊加 = 震更大）|
| 合成冷卻 | 使用 `mergeCooldown Set` 防止同一對形狀在同一幀重複合成 |

## 2.5 形狀數值平衡分析

### 半徑成長曲線

```
半徑(px): 23 → 29 → 36 → 47 → 57 → 70 → 88 → 104 → 125
倍率:      1.0  1.26  1.57  2.04  2.48  3.04  3.83  4.52  5.43
增幅:        +6   +7   +11   +10   +13   +18   +16   +21
```

**設計觀察**：半徑非線性成長，增幅逐級加大。Lv.5（70px）後增幅顯著加速，使大形狀成為高風險高報酬——合成帶來大分數但佔用大量空間。

### 得分成長曲線

```
得分: 1 → 3 → 6 → 10 → 15 → 21 → 28 → 36 → 50
增幅:   +2  +3   +4   +5   +6   +7   +8   +14
近似: 三角形數列 n(n+1)/2 (1,3,6,10,15,21,28,36) + Lv.8 加碼至 50
```

**設計觀察**：Lv.0~7 精確符合三角形數列（第 n 個三角形數 = n(n+1)/2），Lv.8 刻意提升至 50（理論值應為 45），為最終形狀提供額外獎勵感。

### 空間佔用分析

| 等級 | 碰撞面積 (px²) | 佔遊戲區域% | 併排可容納數 |
|------|-------------|-----------|-----------|
| Lv.0 | 1,662 | 0.53% | ~20 個 |
| Lv.4 | 10,207 | 3.28% | ~6 個 |
| Lv.8 | 49,087 | 15.78% | ~2 個 |

> 遊戲區域面積 ≈ 476 × 654 = 311,304 px²

**設計結論**：容器最多可裝 ~2 個 Lv.8 大圓形，空間極為緊張，迫使玩家必須在合成前規劃堆疊位置。

### 理論最高分估算

合成路徑：2×Lv.0 → Lv.1 → ... → Lv.8，需要 2⁸ = 256 個 Lv.0 基礎形狀。

單條完整合成鏈得分 = 3+6+10+15+21+28+36+50 = **169 分**

實際遊戲因空間限制，理論上單局極限約 **2,000–4,000 分**（取決於難度與隨機運氣）。
