## 4.1 美術風格定義

**核心風格**：Cyberpunk / Neon Vector Arcade  
**視覺語言**：霓虹燈光 × 幾何形狀 × 深太空背景

### 設計關鍵詞

- 深色背景（near-black `#0a0a0f`）
- 高飽和度霓虹配色（青色、洋紅、螢光綠、橙色）
- 發光效果（Glow）與加法混合（BlendMode: 'add'）
- 透視網格地板（3D Perspective Grid），Tron / Geometry Wars 氛圍
- 格線光流（Grid Flow）粒子——能量在格線上流動

### 風格參考

- **Tron**：3D 透視地板的網格格線
- **Geometry Wars**：霓虹幾何體在深色空間中的視覺風格
- **蒸汽波（Vaporwave）**：高飽和度漸層色盤
- **Arcade 復古**：Orbitron 等寬科技字型、大寫標題

## 4.3 形狀視覺設計

每個形狀由 `drawNeonShape()` 函數動態生成，包含 3 層視覺結構：

### 三層繪製架構

```
Layer 3 (外): Glow 光暈掃描 ── 3 圈遞減透明度外環
Layer 2 (中): Main Shape    ── 半透明填充 + 粗邊框 + 內圈裝飾
Layer 1 (內): Bubble Overlay ── 圓形泡泡覆蓋（碰撞體可視化）
```

### Glow 層（外環光暈）

**繪製迴圈**：`for (i = 3; i >= 1; i--)` — 由外到內繪製

| 圈 | 擴張半徑 | 透明度 | 公式 |
|----|---------|--------|------|
| 第 3 圈（最先繪製） | radius + 12px | 0.027 | `0.08 / 3` |
| 第 2 圈 | radius + 8px | 0.04 | `0.08 / 2` |
| 第 1 圈（最後繪製） | radius + 4px | 0.08 | `0.08 / 1` |

**公式**：`glowRadius = r + i × 4`，`alpha = 0.08 / i`

### Main Shape（主形狀）

| 元素 | 樣式 |
|------|------|
| 填充 | 形狀顏色，alpha=0.08（極淡填充） |
| 外邊框 | 形狀顏色，width=6，alpha=1.0（全亮） |
| 內圈裝飾 | 半徑 × 0.55，width=3，alpha=0.2 |

### Bubble 覆蓋（碰撞體外殼）

| 元素 | 樣式 |
|------|------|
| 半透明填充 | 形狀顏色，alpha=0.15 |
| 邊框 | 形狀顏色，width=1，alpha=0.2 |
| 半徑 | shape.radius + 3（與碰撞體一致） |

### 多邊形 vs 圓形

- **sides=0**（圓形）：`g.circle()`
- **sides>0**（多邊形）：`g.poly(buildPolygonPoints())`
- 頂點生成：均勻分布在圓上，起始角度 = -π/2（頂部正上方）

## 4.4 環境場景設計

### 3D 透視地板

| 參數 | 數值 | 說明 |
|------|------|------|
| hLines | 8 | 水平格線條數 |
| vLines | 10 | 垂直格線條數 |
| nearExtend | 220px | 近端超出畫面延伸 |
| farOffset | 30px | 遠端距離遊戲區域底部 |
| power | 2.5 | 透視壓縮次方（越大越壓縮） |

**透視計算**：使用 power curve `tC = 1 - (1 - t)^2.5` 模擬近大遠小效果。

**座標定義**：
- `farY` = gameAreaH - farOffset（遠端 Y，地板最遠處）
- `nearY` = canvasH（近端 Y，畫面底部）
- `farL/farR` = 遊戲區域左右邊界（與牆壁對齊）
- `nearL/nearR` = ±nearExtend（近端擴展超出畫面，製造「無限延伸」感）

#### 水平格線繪製

| 屬性 | 值 | 說明 |
|------|-----|------|
| 顏色 | `#00FFFF` | 青色霓虹 |
| 線寬 | 1px | 纖細格線 |
| alpha | `0.5 + 0.5 × (1 - tC)` | **近亮遠暗**：近端 alpha≈1.0，遠端≈0.5 |

> **氛圍意圖**：透過亮度消退模擬「視覺深度」——玩家近端清晰可見，遠端消融於虛空，暗示空間的無限延伸。

#### 垂直格線繪製

| 屬性 | 值 | 說明 |
|------|-----|------|
| 顏色 | `#00FFFF` | 青色霓虹 |
| 線寬 | 1px | 纖細格線 |
| alpha | `(0.35 + 0.35 × (1 - |frac-0.5|×2)) × 0.9` | **中央亮兩側暗** |

> **氛圍意圖**：垂直格線向中央聚焦，自然引導玩家視線回到容器中心——形狀落下的核心區域。兩側格線消退，製造「隧道視覺」效果。

#### 背景微格線（底層氛圍）

在地板和牆壁之下，還有一層近乎不可見的背景微格線：

| 屬性 | 值 | 說明 |
|------|-----|------|
| 方向 | 垂直 | 等間距垂直線 |
| 間距 | 45px | 在遊戲區域內等距排列 |
| 顏色 | `#FFFFFF` | 純白 |
| alpha | 0.025 | 幾乎不可見（2.5%透明度） |
| 線寬 | 1px | 極細 |

> **氛圍意圖**：極淡的微格線在潛意識層面強化「數位空間」的感覺。玩家不會主動注意到它，但移除後會感到「場景少了什麼」。這是環境設計中「感覺不到但不能沒有」的元素。

### 牆壁霓虹線

- 左右垂直線：`#00FFFF`，width=2，alpha=0.6
- 底部水平線：`#00FFFF`，width=2.5，alpha=0.7

### Game Over 判定線

- 紅色虛線，Y=55，寬 8px dash + 6px gap
- 顏色 `#FF3131`，width=1.5，alpha=0.35

## 4.5 隱性世界觀

> **設計備注**：本遊戲為無敘事益智遊戲，採用「隱性世界觀」——透過視覺環境暗示主題，無文字故事。

### 環境敘事設定

| 元素 | 隱性含義 |
|------|---------|
| 霓虹幾何體 | 數位能量晶體，不同頻率/形態 |
| 合成升級 | 同頻共鳴，融合為更高維度形態 |
| 3D 地板格線 | 數位空間座標系 |
| 格線光流 | 數位空間中流動的能量脈衝 |
| 遊戲結束 = 堆出容器 | 能量容器溢出，系統崩潰 |
| 深黑背景 | 虛空中的數位微宇宙 |

### 形狀能量隱喻

每個形狀等級對應不同的「能量維度」，透過顏色與形態傳達：

| 等級 | 形態 | 能量隱喻 | 色彩敘事 |
|------|------|---------|--------|
| Lv.0 Triangle | 最簡幾何 | 基礎能量種子——不穩定的三角脈衝 | 青色 = 初始冷電流 |
| Lv.1 Small Circle | 首次圓化 | 能量凝聚，開始形成穩定場 | 黃色 = 暖化啟動 |
| Lv.2 Square | 四方穩定 | 結構化能量——可疊加的基礎單元 | 珊瑚紅 = 能量升溫 |
| Lv.3 Pentagon | 五芒形態 | 複雜共振開始——超越基礎幾何 | 螢光綠 = 生命脈動 |
| Lv.4 Hexagon | 蜂巢結構 | 高效能量排列——自然界最穩定形態 | 橙色 = 熱力釋放 |
| Lv.5 Circle | 完美圓形 | 能量球體——維度跳躍的臨界點 | 洋紅 = 高維輻射 |
| Lv.6 Large Square | 巨型方陣 | 能量矩陣——空間扭曲的力場 | 紫色 = 暗能量 |
| Lv.7 Large Hexagon | 巨型蜂巢 | 宇宙級能量結構——跨維度共振體 | 青綠 = 冷卻回歸 |
| Lv.8 Large Circle | 終極球體 | 圓滿——不可再分裂的統一場 | 白色 = 所有光的合一 |

### 格線光流的方向敘事

- 60% 水平流動 → 暗示能量在同一維度內傳導
- 40% 垂直流動 → 暗示能量試圖跨維度躍遷
- Light flow 在近端（玩家側）較亮、遠端漸滅 → 暗示能量從外部源源注入容器

### 命名哲學

遊戲名 **"Neon Shape Merge"** 直白表達核心玩法（霓虹 + 形狀 + 合成），視覺語言即是敘事，不需額外故事包裝。

## 4.6 Design Token 系統

將散落各處的顏色、字型、間距統整為語意化 Design Token，方便維護與未來擴展：

### 顏色 Token

| Token 名稱 | 值 | 語意用途 |
|-----------|-----|--------|
| `--color-bg-primary` | `#0a0a0f` | 全域背景 |
| `--color-bg-secondary` | `#0d0d1a` | 容器背景 |
| `--color-bg-surface` | `#0f0f23` | 遊戲區域底色 |
| `--color-accent` | `#00FFFF` | 主要強調色（牆壁、分數、按鈕） |
| `--color-danger` | `#FF3131` | 危險色（Game Over、Hard 按鈕） |
| `--color-success` | `#39FF14` | 正向色（Easy 按鈕） |
| `--color-gold` | `#FFD700` | 獎勵色（COMBO、排行榜） |
| `--color-settings` | `#AAAAFF` | 設定介面色 |
| `--color-text-primary` | `#FFFFFF` | 主要文字 |
| `--color-text-muted` | `rgba(255,255,255,0.4)` | 次要標籤文字 |

### 字型 Token

| Token 名稱 | 值 | 用途 |
|-----------|-----|------|
| `--font-display` | `'Orbitron', sans-serif` | 標題、分數、按鈕（科技感等寬） |
| `--font-body` | `'Rajdhani', sans-serif` | 內文、排行榜名字（可讀性） |
| `--font-size-score` | `48px` | 分數數值 |
| `--font-size-title` | `36px` | Game Over 標題 |
| `--font-size-subtitle` | `28px` | 難度選擇標題 |
| `--font-size-button` | `22px` | 難度按鈕文字 |
| `--font-size-label` | `16px` | HUD 標籤 |
| `--font-size-small` | `13px` | 描述文字 |

### 動畫 Token

| Token 名稱 | 值 | 用途 |
|-----------|-----|------|
| `--transition-fast` | `0.25s ease` | 按鈕 hover |  
| `--transition-normal` | `0.3s ease` | Overlay 出現 |
| `--transition-slow` | `0.5s ease` | 難度選擇淡入 |
