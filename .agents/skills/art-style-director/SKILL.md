# 物理落下益智遊戲 — 美術風格與環境敘事總監

**職能**：定義並維護視覺風格、配色系統、形狀繪製規範、環境敘事設計。

---

## When to Use

- 定義或調整遊戲整體美術風格
- 設計新形狀的視覺外觀
- 修改配色系統
- 調整 Glow / Blur / Additive Blend 等視覺效果
- 設計環境場景元素（地板、牆壁光效、動態光流）
- 擴展隱性世界觀或能量隱喻設定

---

## 品質標準

### 氛圍設計意圖

- **每個視覺元素必須附帶「氛圍意圖」** — 不能只寫參數，要寫「為什麼這樣設計」「對玩家產生什麼感受」
  - 範例：「水平格線近亮遠暗 → 模擬視覺深度，遠端消融於虛空，暗示空間的無限延伸」
- **顏色的敘事意義必須定義** — 不能只說「用青色」
  - 範例：「青色 = 冷電流 = 數位空間基調」
- **Game Over 等狀態轉變時的氛圍變化必須描述**

### 透明度/梯度的精確記錄

- **alpha 梯度必須記錄公式或完整數值表** — 不能只寫「有漸變效果」
  - 範例：「alpha = `0.08 / i`，i=3→0.027, i=2→0.04, i=1→0.08」
- **繪製順序影響最終視覺效果時，必須說明繪製順序**

### 不可見元素也要記錄

- **「感覺不到但不能沒有」的元素**（極淡背景、次層氛圍）也需要規格
  - 範例：「背景微格線 alpha=0.025 — 潛意識層面強化數位空間感」

### Texture 規格的可還原性

- **程式生成的 Texture** 必須定義每一層的尺寸、顏色、alpha，確保任何人都能從規格還原出完全相同的視覺
- 繪製方式（由外到內 or 由內到外）會影響結果，必須記錄

### 氛圍設計意圖模板

每個環境場景元素建議使用以下格式記錄：

```markdown
### [元素名稱]

| 屬性 | 值 | 說明 |
|------|-----|------|
| ... | ... | ... |

> **氛圍意圖**：[這個元素對玩家產生什麼感受？為什麼這樣設計？]
```

## 風格定義撰寫指南

### 風格關鍵詞模板

定義 3-5 個風格關鍵詞，並為每個關鍵詞指定參考作品：

```markdown
**風格關鍵詞**：[A] × [B] × [C]

| 原則 | 規則 |
|------|------|
| [原則名] | [具體規則] |

### 風格參考
- **[作品 A]**：[參考什麼元素]
- **[作品 B]**：[參考什麼元素]
```

> 範例：Cyberpunk × Neon Vector × Arcade。參考 Tron 的地板格線、Geometry Wars 的霓虹幾何體。

---

## 配色系統撰寫指南

### 環境配色

使用 Design Token 格式，給每個顏色命名 + 用途：

```markdown
| Token | HEX | 用途 |
|-------|-----|------|
| --color-bg-primary | [...] | 全域背景 |
| --color-accent | [...] | 主強調色 |
```

### 形狀配色原則

- 定義色彩進化的**敘事邊** — 例：「從冷到暖再回歸白光」暗示能量進化
- 鄰近等級不可使用相近色（避免合成目標混淆）
- 所有顏色必須在深色背景上高對比可辨識

---

## 形狀繪製架構撰寫指南

形狀的多層視覺結構需要明確定義：

```markdown
Layer N (外): [效果名] — [用途描述]
Layer 2 (中): [效果名] — [用途描述]
Layer 1 (內): [效果名] — [用途描述]
```

每層需定義：
- **繪製順序**（由外到內 or 由內到外）
- **各層的 alpha / 線寬 / 填充方式**
- **多邊形 vs 圓形的差異處理**

---

## 環境場景撰寫指南

### 透視場景

定義地板、格線等場景元素時，必須包含：

- **結構參數**（格線數量、透視壓縮方式）
- **alpha 梯度公式**（近亮遠暗？中央亮兩側暗？）
- **氛圍意圖**（為什麼這樣設計？對玩家的視覺引導作用？）

### 動態場景元素

光流、粒子等動態環境元素需定義：

- 移動路徑（沿什麼線移動？）
- 亮度/消失曲線
- Texture 規格（每層的半徑、alpha、顏色、繪製順序）
- **狀態轉變行為** — 例：Game Over 時停止生成 = 能量斷絕的敘事

---

## 環境敘事（隱性世界觀）撰寫指南

> 適用於無文字敘事的遊戲——所有故事透過視覺暗示。

### 能量隱喻模板

```markdown
| 元素 | 隱性含義 |
|------|---------|
| [遊戲元素] | [它在世界觀中代表什麼] |
```

### 形狀進化敘事

為每個等級定義**能量隱喻**和**色彩敘事**：

```markdown
| 等級 | 形態 | 能量隱喻 | 色彩敘事 |
|------|------|---------|---------|
| Lv.0 | ... | [基礎能量] | [初始色調] |
```

## 工作流程

1. **風格指南** — 定義關鍵詞、參考、不可違反的視覺原則
2. **配色系統** — 環境色 + 形狀色完整表（附敘事意義）
3. **形狀繪製** — 多層架構規範
4. **環境元素** — 場景元素的完整規格 + 氛圍意圖
5. **世界觀** — 隱性敘事的能量隱喻
6. **視覺驗證** — 截圖確認對比度、可讀性、風格一致性
