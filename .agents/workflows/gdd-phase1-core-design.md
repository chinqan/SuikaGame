# Phase 1：核心設計（game-designer）

> **調用 Skill**：`game-designer`
> **產出檔案**：`docs/gdd/01_game_overview.md`
> **前置依賴**：用戶已確認遊戲定位、目標平台、風格方向

---

## Step 1.1 — 設計支柱定義

1. 讀取 `game-designer` Skill 中的「設計支柱」段落
2. 與用戶討論確認 **3 個設計支柱**（Design Pillars）
3. 每個支柱需包含：
   - **支柱名稱**（一句話）
   - **如何實現**（具體機制對應）
   - **底線**（違反這條就不算合格的遊戲）

**產出格式範例**：
```markdown
### 設計支柱

1. **「再來一局」衝動** — ...透過[具體機制]實現
2. **COMBO 爽感** — ...
3. **策略深度的錯覺** — ...
```

**檢查點**：
- [ ] 3 個支柱互不重疊
- [ ] 每個支柱能直接對應至少 1 個遊戲機制

---

## Step 1.2 — 核心循環撰寫

1. 使用 Skill 中的「核心循環寫作模板」
2. 依序撰寫 3 層循環：

### Moment-to-Moment（0–10 秒）
- 用流程圖描述玩家每次操作的決策點
- 標明每一步的**視聽回饋**（看到什麼、聽到什麼）

### Session Loop（每局）
- 描述一局遊戲的完整弧線
- 標明情緒轉折點

### Long-Term Loop（跨局）
- 排行榜、解鎖、挑戰等元循環

**檢查點**：
- [ ] 每層循環有流程圖或步驟描述
- [ ] 回饋系統（視覺/音效）與循環對應

## Step 1.4 — 情感設計弧線

使用 Skill 中的 Pacing Chart 模板：

```
時間      | 活動    | 張力    | 情緒
----------|--------|--------|----------------
[時間段]   | [活動]  | [等級]  | [情緒描述]
```

**檢查點**：

## Step 1.5 — 合成機制完整規格

使用 Skill 中的「規則定義模板」逐項定義：

### 基本合成規則
- **輸入**：觸發條件（碰撞判定方式）
- **處理**：合成邏輯（消除 → 生成 → 得分）
- **輸出**：視覺效果 + 音效 + 分數
- **邊界條件**：最高等級碰撞、多對同時碰撞、連鎖合成

### 合成後物理行為
- 新形狀的初始速度（方向、大小範圍）
- 畫面震動公式（需包含等級和 COMBO 的影響因子）
- 合成冷卻機制

### COMBO 機制
- 窗口時間
- 計數方式
- 視覺/音效回饋的遞增
- 重置條件

**檢查點**：
- [ ] 每條規則有「輸入→處理→輸出→邊界條件」
- [ ] 合成後物理行為有完整公式
- [ ] COMBO 有具體數值（窗口時間、計數邏輯）

| 變數 | Easy | Normal | Hard | 設計意圖 |
|------|------|--------|------|---------|
| ... | ... | ... | ... | ... |

### 平衡原則
