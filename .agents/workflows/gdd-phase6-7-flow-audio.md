**檢查點**：
- [ ] 涵蓋所有 Phase 3 架構圖中的模組
- [ ] 有明確的順序依賴

---

## Step 6.2 — 主遊戲循環

定義每幀（tick）的執行步驟順序：

```markdown
每幀步驟：
1. 物理引擎 step
2. 同步 Sprite 位置
3. 更新粒子系統
4. 更新瞄準線
5. 檢查 Game Over
6. ...
```

**檢查點**：
- [ ] 物理更新在渲染更新之前
- [ ] Game Over 檢查在物理之後

---

## Step 6.3 — 合成觸發流程

詳細描述碰撞事件到合成完成的每一步，使用流程圖：

```
碰撞事件觸發
  → 檢查 label / level / cooldown
  → 移除舊 body + graphic
  → 計算得分 + COMBO
  → 生成新形狀（設定初速）
  → 觸發粒子 + 音效 + 震動
  → 更新分數 UI
```

---

## Step 6.4 — Game Over 流程

```
檢查觸發 → 延遲確認 → 顯示 Overlay
  → 上傳分數 → 等待重新開始
```

定義：延遲時間、分數上傳邏輯、Overlay 顯示內容

---

## Step 6.5 — 重置流程

清理順序：
```
1. 清理所有 Body
2. 清理所有 Sprite
3. 清理所有粒子
4. 重置分數/COMBO
5. 重新初始化
```

**檢查點**：
- [ ] 每個系統的清理行為有定義
- [ ] 不會有殘留物件

---

## Phase 6 完成驗收

- [ ] 初始化有順序
- [ ] 主循環有幀步驟
- [ ] 合成流程有完整流程圖
- [ ] Game Over 有延遲+上傳邏輯
- [ ] 重置有完整清理清單
